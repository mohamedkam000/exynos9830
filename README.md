<h1 align="center">Raptor</h1>
<p align="center"><b>Open Source Android Kernel Source for Exynos 990</b></p>

---

## Overview

This is a modified source code for the Exynos 9830 platform. It is meant to be used mainly on AOSP ROMs.

<b></b>

## Features

- WireGuard.
- A lot less restrictions.
- Lightweight and fast.
- A lot of unnecessary configs removed.

<b></b>

## Use Cases

- AOSP ROMs.
- Testing.
- A base for upstreaming.
- For power users to run experiments.
